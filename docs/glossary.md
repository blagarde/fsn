# Glossary

| Term | Meaning |
| --- | --- |
| β, βeff | Delayed-neutron fraction (effective: weighted by importance). Pu-239 ≈ 0.0021, U-235 ≈ 0.0065 |
| BR | Breeding ratio: fissile atoms produced per fissile atom destroyed |
| CALPHAD | Computational thermodynamics method for phase diagrams from assessed Gibbs-energy models |
| Claims check | Automated comparison of figures in these docs with the property database ([data/claims-check.md](data/claims-check.md)) |
| DBTT | Ductile-to-brittle transition temperature |
| Designation | Ten-code string classifying a design on the [taxonomy](framework/taxonomy.md) axes |
| Direct contact (DC) | Heat removal by a carrier passed through liquid fuel with no wall between them |
| Doubling time | Time to accumulate a second core's worth of fissile material |
| dpa | Displacements per atom: radiation damage dose in structural materials |
| ENDF/B-VIII.0 | US evaluated nuclear data library (2018) used as the reference cross-section source |
| Exergy | Work-equivalent of heat at temperature T: Q (1 − T0/T) |
| FIMA | Fissions per initial metal atom (burnup); 1% ≈ 9.5 GWd/tHM |
| Fission-spectrum average | Cross section weighted by the U-235 thermal-fission (Watt) neutron spectrum; a stand-in until core spectra are computed |
| JANAF | NIST-JANAF Thermochemical Tables (4th ed., 1998) |
| k∞, keff | Infinite-medium and effective neutron multiplication factors |
| LiveChart | IAEA nuclide chart API (half-lives, abundances, decay modes) |
| MT number | ENDF reaction identifier: 2 elastic, 18 fission, 101 non-fission absorption, 102 capture, 103 (n,p), 105 (n,t), 107 (n,α) |
| NJOY | Nuclear data processing code (resonance reconstruction, Doppler broadening) |
| Stack | Compatible set of fuel, cladding, coolant, structure and working fluid |
| T1–T5 | Core outlet temperature classes: < 550, 550–750, 750–950, 950–1,200, > 1,200 °C |
| ξ | Mean logarithmic energy loss per elastic collision; measure of moderating power per collision |
