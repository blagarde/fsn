| [Aluminium as coolant](aluminium-coolant.md) | What boundaries survive molten aluminium? | Diborides (B-11), AlN, and oxides more stable than Al2O3 | [A1](../designs/A1.md), [A2](../designs/A2.md), [A3](../designs/A3.md) | 2026-11-19 |
