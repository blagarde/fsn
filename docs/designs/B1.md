# B1: Lithium-cooled nitride

Seed branch from the [taxonomy](../framework/taxonomy.md#known-reactors-classified): it survives the exclusion rules and reaches T3–T4. Not yet analysed beyond this summary.

SP-100 heritage (UN fuel, Nb-1Zr, Li-7 at ~1,075 °C) turned into a breeder. Lithium boils at 1,342 °C, so T4 is reachable at low pressure. Lithium dissolves nickel strongly, so only refractory metals can contain it, with oxygen in Nb kept at ppm level. Li-7 must be enriched beyond 99.9% to limit Li-6 absorption and tritium.
